# Справка бота: правила сервиса и база знаний

Статическая страница, которую бот открывает по кнопке «❓ Как это работает».
Один самодостаточный `index.html` — ни сборки, ни зависимостей.

Публикуется через GitHub Pages из ветки `main`.

Исходник страницы живёт в приватном репозитории проекта (`site/index.html`);
сюда он копируется скриптом `scripts/publish_help_site.sh` — правь там, не здесь.
