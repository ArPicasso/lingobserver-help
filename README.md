# Saturn help centre

The rules and knowledge base page of **Saturn**, a Telegram bot for practising English in anonymous text chats. The bot opens this page from its "How it works" button.

**Live page:** [arpicasso.github.io/lingobserver-help](https://arpicasso.github.io/lingobserver-help/) (in Russian)

## How it is built

One self-contained `index.html` with inline styles, no build step and no dependencies. It is published with GitHub Pages from the `main` branch.

The source of the page lives in the bot's private repository and is copied here by a publish script, so changes should be made there, not in this repository.

Original note in Russian: [README.ru.md](README.ru.md).
